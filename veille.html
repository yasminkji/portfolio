Laravel & Développement d'API REST

Dans le cadre de mon BTS SIO option SLAM, j'ai effectué une veille active sur Laravel, framework PHP moderne, et sur les bonnes pratiques de conception d'API REST — deux technologies au cœur de mon stage et de mes projets.

Laravel

Qu'est-ce que Laravel ?

Laravel est un framework PHP open-source apparu en 2011, conçu pour simplifier le développement web grâce à une meilleure syntaxe et des outils intégrés (routing, ORM Eloquent, Blade, Artisan...).

API REST

Qu'est-ce qu'une API REST ?

Une API REST (Representational State Transfer) est une interface qui permet à deux applications de communiquer entre elles via HTTP. Elle repose sur des ressources accessibles par des URLs et des méthodes standardisées (GET, POST, PUT, DELETE).

Laravel + API REST

Laravel pour construire des API :

Laravel propose des outils puissants pour créer des API REST : ressources Eloquent, authentification via Sanctum ou Passport, gestion des routes API, et retour JSON automatisé.

Pourquoi ce sujet ?

Lien avec mon parcours :

Durant mon stage chez SHOEMAKERS Group, j'ai travaillé sur la migration d'un site B2B vers Laravel. Cette expérience m'a poussée à approfondir le framework et à comprendre comment structurer des API REST robustes.
